# OMol25 bonds and discovery: working papers

The plan of record is [`docs/omol25-bonds-and-discovery.md`](../../omol25-bonds-and-discovery.md).
This folder keeps what produced it:

- `research-*.md`: the five research reports (how OMol25 reaches the viewer, the
  bond pipeline, discovery surfaces, what the OMol25 releases contain, and bond
  perception methods). External claims cite their sources.
- `contracts.md`: the shared types, strings and file ownership the build tracks
  were written against.
- `tracks.json`: the four build tracks (A bond engine, B viewer, C edge data,
  D surfaces).
