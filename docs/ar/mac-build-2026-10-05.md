# Native Lupi: first Mac build

2026-10-05. Starting source: PR #125 at
`fb70f6e40b29a4ed9399c878b6ed46662f5806bb`.

The native app builds against the real Apple SDK. Physical AR and signing
remain pending. This record supplements [status.md](status.md), which owns
the on-device checklist.

## Environment and fixes

- Xcode 26.6, build 17F113; iOS SDK and Simulator runtime 26.5.
- Apple Swift 6.3.3; XcodeGen 2.46.0.
- `project.yml` generated the local Xcode project, Info.plist and entitlements.
  Generated files and build outputs stay out of git.
- `PlayController.swift` now imports SwiftUI, which enables the RealityKit
  SwiftUI overlay containing `RealityViewCameraContent`.
- `TouchCaptureView`'s counter is now `nextTouchID`; `next` conflicted with
  UIKit's inherited responder property. Touch ID allocation is unchanged.
- `ARHost.start` skips tracking on the Simulator, where the SDK omits
  `SpatialTrackingSession.run(_:session:arConfiguration:)`. The device path
  continues to use the owned ARSession, camera and world-map configuration.

The type's documented role is described in Apple's
[RealityViewCameraContent reference](https://developer.apple.com/documentation/realitykit/realityviewcameracontent).
The installed SDK interfaces and the actual compiler establish the import
and Simulator differences above.

The Mac totals are 552 debug tests and 285 release tests. The package checks exercise the headless
logic; neither those tests nor Simulator screens prove physical AR behaviour.
The camera explanation was dismissed with **Not now**, before a camera
permission request. Firebase account configuration was not added.

Both app builds used `CODE_SIGNING_ALLOWED=NO`. The final device log is
`ios-build-03.log`; the Simulator log is `simulator-build-02.log`. Package
logs and four Simulator screenshots were retained with the local task's
outputs. A first LupiGame release compile exhausted disk space; caches made
by this run were removed and the native-only checkout retained before retry.
Existing user files and Simulator data were preserved.

```bash

```
